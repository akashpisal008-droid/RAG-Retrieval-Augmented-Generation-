# RAG Pipeline Project

## 📌 Overview
This project implements a Retrieval-Augmented Generation (RAG) pipeline that retrieves relevant information from documents using semantic search.

## 🚀 Features
- Document loading and processing
- Text chunking using RecursiveCharacterTextSplitter
- Text embeddings using Sentence Transformers
- Vector storage using ChromaDB
- Similarity search for retrieving relevant document chunks

## 🛠️ Technologies Used
- Python
- LangChain
- ChromaDB

## ⚙️ How It Works
1. Load documents.
2. Split documents into smaller chunks.
3. Convert text chunks into numerical embeddings.
4. Store embeddings in ChromaDB.
5. Retrieve relevant chunks based on a user query.

## 📚 Key Learnings
- Understanding text embeddings and semantic similarity
- Learning chunk size and chunk overlap
- Building a modular RAG pipeline
- Understanding vector databases and document retrieval

## 🔮 Future Improvements
- Integrate an LLM for answer generation
